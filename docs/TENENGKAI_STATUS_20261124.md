# 特会开交接总结（2026-11-24）

特会开是 TesNav 的 Android 变体，包名 `com.garan.tesnav.tenengkai`。它把高德 SDK 或高德车机版的导航状态发给 C3/C3XL 的 NavAssist，并在平板显示导航、车辆状态和实景入口。高德车机版可在平板上嵌入显示，也可通过 Tesla BLE 同步车上发来的目的地。

## 源码和可核对版本

- Android 源码快照为 `15620eafa6c5d889dd9cf615ef5cee0d1a91a7c9`。当时 `assembleTenengkai` 成功，372 项单测有 3 项失败、1 项跳过。失败涉及原有导航协议和车道映射快照。该提交保留了当时未验收的独立高德定位接入试验。[源码快照说明](SOURCE_SNAPSHOT_20261026.md)
- 现有 iOS TesNav 在 `53a98ff351d4b2ad20d6d10da91402ffeaaf18eb` 构建过未签名 IPA。Android 特会开的实景桥接和车机界面嵌入仍是 Android 功能。[iOS 构建记录](https://github.com/juyun86/TesNav/actions/runs/40333920724)
- 要构建 Android 变体，使用 `assembleTenengkai`。`arcompat` 是高德原生 AR 所需的独立相机兼容入口，构建任务为 `:arcompat:assembleDebug`。两个 APK 使用同一签名，地图 Key 在本地配置。[实景接入结构与构建](C3_AMAP_AR.md)

## 和 C3XL 的接口

特会开向 C3XL 的 NavAssist 传输路线进度、转向、匝道和车道提示，并按会话和序号接收确认。完整路线处理及可选模型输入另有本地实验。普通 C3 的 AR 画面和定位提交记录不能用于验收 C3XL 的车辆识别、模型或实际驾驶行为。普通 C3 的官方导航模型研究见[此前的交接资料](https://github.com/juyun86/TesNav/tree/main/docs/c3-official-navigation-20261107)。
